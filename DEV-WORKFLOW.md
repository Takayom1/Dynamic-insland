# Локальная разработка

Промежуточные исправления проверяются локально без коммитов, тегов, релизов и установщиков. После подтверждения результата и явной просьбы Takayom1 опубликовать изменения можно собрать новый релиз. Между такими выпусками версия не повышается. Проверенные изменения входят в 0.17.0.

`scripts/update-local.ps1` собирает приложение, просит работающий остров корректно завершиться, заменяет локальные файлы и запускает его снова. Инсталлятор не используется. Если есть активная команда, запись, черновик, таймер или секундомер, остров отказывается перезапускаться. Аккаунт, история, vault и калибровка лежат вне папки программы и не перезаписываются.

Для первого перехода со старой сборки требуется один раз выйти через меню в трее: в ней ещё нет команды локального перезапуска. Последующие проверки используют её автоматически. Одна предыдущая копия заменяемых файлов хранится в `work/local-backup`.

Маркер `.local-dev` выключает проверку публичных обновлений. Финальный установщик и новая версия создаются только после одобрения пользователя.

Изменения 0.17: выбор монитора (по умолчанию основной), исправление ложного полноэкранного режима, отдельная громкость голоса, тихие сигналы Kenney CC0 и распознавание команд faster-whisper. Модель Whisper и Python выбираются отдельно; текущая установка пользователя может оставаться на проверенной локальной сборке без повторного запуска установщика.

В настройках «Помощник и аккаунт» выбери Whisper, папку локальной модели faster-whisper и Python с пакетами faster-whisper / CTranslate2. На этом ПК подготовлена модель `outputs/voice-models/faster-whisper-small` и Python `work/rvc-gpu-env/Scripts/python.exe`. Это локальные пути разработчика, они не включаются в релиз. Запись сохраняется во временный WAV для локального распознавания и удаляется после запроса. После голосовой активации распознанный текст отправляется в чат; диктовку по кнопке сначала можно проверить.

Пауза окончания фразы по умолчанию 1,6 секунды, предел записи — 30 секунд. Настройки громкости Хошино и её сигналов не изменяют общую громкость Windows. Игровой режим освобождает модели, поэтому после выхода из игры им снова нужен прогрев.
